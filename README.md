#Pet Adoption Portal

A full-stack web application developed to simplify the pet adoption process by connecting adopters with available pets through an interactive and user-friendly platform.

#Project Overview

The Pet Adoption Portal allows users to browse pets, register accounts, log in securely, and manage adoption activities through dedicated dashboards. The system was developed as a final year project using frontend and backend web technologies.

#Features
User Registration and Login Authentication
Admin and User Dashboard
Pet Listing and Category Management
Adoption Request Management
Database Integration using MySQL
Responsive User Interface
Secure User Data Handling
